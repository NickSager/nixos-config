
## Host-neutral worker bootstrap

When delegating through a host that has no named `poteto-agent` role, use its generic worker mechanism with this instruction: read the Poteto Mode skill in full before doing any work, then read every applicable `principle-*` skill before applying that principle. Pass file paths instead of inlining large files. Preserve the selected playbook's requested worker model, background mode, and read-only or writable boundary.
