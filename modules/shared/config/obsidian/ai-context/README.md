# AI Context

Shared context files for Claude Code. Reference from any project's CLAUDE.md.

## Usage

In a project's CLAUDE.md, point to files here:

```
Check ~/Documents/Notes/AI/Context/<file>.md for context on <topic>
```

## Structure

- One file per long-running project or service
- Team context: members, roles, communication patterns
- Architecture: cross-cutting decisions and patterns
